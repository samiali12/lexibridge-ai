# ⚖️ LexiBridge AI – Legal RAG System

LexiBridge AI is a **Retrieval-Augmented Generation (RAG)** based application built with **Streamlit**, designed to answer legal questions by retrieving information from Pakistani laws and legal documents.  

🔗 **Live Demo**: [LexiBridge AI](https://lexibridge-ai-dfxzoqwhupxedrdvawxgrq.streamlit.app/)

---

## 🚀 Features
- ✅ Ask legal questions in **natural language**
- ✅ Retrieve answers from a curated dataset of legal documents
- ✅ **Source highlighting** – see where the answer came from
- ✅ **Multi-language support** (English & Urdu)
- ✅ Download your conversation in **TXT** or **JSON**
- ✅ User-friendly **chat interface** with history
- ✅ Deployable on **Streamlit Community Cloud**

## ⚙️ Installation & Setup

Clone the repository:
```bash
git clone https://github.com/your-username/lexibridge-ai.git
cd lexibridge-ai
```

Create a virtual environment and activate it:
```bash
python -m venv venv
# On Windows
venv\Scripts\activate
# On Linux/Mac
source venv/bin/activate

Install dependencies:
pip install -r requirements.txt
```

Create a .env file in the project root and add your API keys:
```bash
GOOGLE_API_KEY=your_google_gemini_key
```

Start the Streamlit app:

```bash
streamlit run app.py
```

The app will run at http://localhost:8501/

## 🌐 Deployment (Streamlit Cloud)

Push your repo to GitHub

- Go to Streamlit Community Cloud

- Connect your GitHub repo

- Set your environment variables in Streamlit dashboard

- Deploy 🚀

## 📚 Tech Stack

- Streamlit – UI framework

- LangChain – RAG pipeline

- ChromaDB – Vector database

- Deep Translator – Multi-language support

- Google Gemini – LLM for answering questions
